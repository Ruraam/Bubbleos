# ULPM Integration

`/ulpm` is a BubbleOS-maintained copy of ULPM.

Rules:

1. Do not modify ULPM behavior without a BubbleOS requirement.
2. Keep BubbleOS-only logic outside ULPM when possible.
3. Document every BubbleOS-specific ULPM change.
4. Generic improvements may later be ported back to the upstream ULPM project.

The initial BubbleOS scaffold does not modify the copied ULPM tree.
