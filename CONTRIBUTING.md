🤝 BubbleOS is looking for contributors!

BubbleOS is an independent Linux operating system project, built from the ground up with a focus on performance, lightweight resource usage and real hardware compatibility.

It already boots on physical hardware, including older PCs and low-cost mini-PCs.

I'm looking for people interested in helping the project grow!

Areas where help is welcome:

- Linux kernel and system development
- Rust and Bash programming
- Boot process and system integration
- Btrfs, snapshots and system recovery
- Hardware testing and bug reporting
- Desktop environment and Wayland development
- Documentation and testing

You don't need to be an expert. Enthusiasm, curiosity and a willingness to contribute are just as valuable.

This is an independent open-source project, and I'd love to build a community around it.

Let's build something together! 🚀
